\# Colour Palette Specification: Rick \& Morty AI Executor



This document defines the hexadecimal and RGB colour constants for the Rick \& Morty themed Roblox AI UI system. These schemes establish the visual identity for backgrounds, interactive states, portals, and character-driven UI modes.



\## 1. Primary Structural Theme (The Citadel Space Backgrounds)



The base interface surfaces mimic dark, cosmic, high-tech control panels. They use deep, desaturated space tones to keep the focus on vibrant neon UI elements.



| Element Role | Color3 (Hex) | RGB Value | Visual Description |

| :--- | :--- | :--- | :--- |

| \*\*Main Window Background\*\* | `#0D1117` | `13, 17, 23` | Deep space obsidian black. |

| \*\*Secondary Panels / Sidebar\*\*| `#161B22` | `22, 27, 34` | Dark console slate gray. |

| \*\*Inner Card Panels / Frames\*\*| `#21262D` | `33, 38, 45` | Medium control panel accent gray. |

| \*\*Borders \& Dividers\*\* | `#30363D` | `48, 54, 61` | Metallic structural trim. |



\---



\## 2. Neon Energy Accents (The Portal Grid)



Vibrant neons represent energy sources, active portal gates, and functional UI highlights. Use these sparingly for glow effects, selected tabs, and interactive states.



| Element Role | Color3 (Hex) | RGB Value | Visual Description |

| :--- | :--- | :--- | :--- |

| \*\*Portal Green (Active State)\*\*| `#00FF88` | `0, 255, 136` | Neon radioactive fluid green. |

| \*\*Dimension Pink (Warning)\*\*   | `#FF007F` | `255, 0, 127` | Fluid battery pink-magenta. |

| \*\*Portal Blue (System Link)\*\* | `#00E1FF` | `0, 225, 255` | Liquid plasma cyan. |



\---



\## 3. Character Theme Profiles



When switching modes or configuring the AI character personality, the UI applies specific color overlays to differentiate Rick's scientific aesthetic from Morty's nervous energy.



\### Rick Sanchez Mode (Genius Sci-Fi)

\* \*\*Accent Highlight\*\*: `#A2E8DD` (RGB: `162, 232, 221`) – Lab coat / hair blue-gray.

\* \*\*Text Highlight\*\*: `#00FF88` (RGB: `0, 255, 136`) – Portal fluid green.

\* \*\*Status Glow\*\*: `#00BCFF` (RGB: `0, 188, 255`) – Battery cell blue.



\### Morty Smith Mode (Anxious Sidekick)

\* \*\*Accent Highlight\*\*: `#FFE600` (RGB: `255, 230, 0`) – T-shirt yellow.

\* \*\*Text Highlight\*\*: `#FFAA00` (RGB: `255, 170, 0`) – Alert amber.

\* \*\*Status Glow\*\*: `#FF5500` (RGB: `255, 85, 0`) – Panic orange.



\---



\## 4. Interactive State Variations (Hover \& Press)



Buttons, dropdown lists, and text inputs dynamically transition between these specific hex values based on user input.



\### Portal Green Interactive Sequence

\* \*\*Idle State\*\*: `#00BD65` (RGB: `0, 189, 101`) – Medium radioactive green.

\* \*\*Hover State\*\*: `#00FF88` (RGB: `0, 255, 136`) – Full neon portal glow.

\* \*\*Pressed State\*\*: `#008044` (RGB: `0, 128, 68`) – Deep battery fluid drain green.



\### Dark Console Interactive Sequence

\* \*\*Idle Frame\*\*: `#21262D` (RGB: `33, 38, 45`) – Neutral dark gray.

\* \*\*Hover Frame\*\*: `#30363D` (RGB: `48, 54, 61`) – Lightened panel edge.

\* \*\*Pressed Frame\*\*: `#161B22` (RGB: `22, 27, 34`) – Sunken inset pane.
