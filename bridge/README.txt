Rick & Morty AI Executor - Cowork bridge
========================================

This folder was generated by the in-game executor. It runs the full-sized
cowork interface outside of Roblox, at http://localhost:7896.

Requirements
------------
  * Node.js 18 or newer (https://nodejs.org)

Start the bridge
----------------
  Windows      : double-click launch_bridge.bat
  macOS / Linux: run ./launch_bridge.sh

Then open http://localhost:7896 in any browser.

Files
-----
  server.js          Node HTTP server: serves the UI and talks to the provider
  index.html         the external high-fidelity interface
  config.json        active provider, model, companion and API key (from the UI)
  launch_bridge.bat  Windows launcher
  launch_bridge.sh   macOS / Linux launcher

Notes
-----
  * config.json holds your API key in plain text. Keep this folder private.
  * Requests are made from Node, so Roblox's HTTP domain whitelist does not
    apply and nothing is proxyed through a third party.
  * Change providers or keys in the Roblox UI and press "Generate bridge"
    again; config.json is rewritten on the spot.
